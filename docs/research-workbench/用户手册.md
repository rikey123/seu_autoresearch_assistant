# 科研工作台用户手册（中文）

> 适用版本：seu_autoresearch_assistant 主分支（P5 阶段，2026-09-02）
> 基座：Hermes Studio。本文档只描述科研工作台在其上新增/定制的功能，基座通用能力（多 Agent 聊天、群聊、文件管理、设置等）请参考基座文档。

## 1. 快速开始

### 1.1 启动

在仓库根目录执行（开发模式）：

```bash
npm install --ignore-scripts
npm run dev
```

- 客户端开发地址：<http://localhost:8649>（Vite，热更新）
- 服务端地址：http://localhost:8647（Koa，nodemon 自动重启）
- 首次访问需要在设置页配置/登录 Hermes 服务（JWT），登录成功后即可使用全部功能。

### 1.2 翻译/编译/问答类功能的前置配置

P3/P4 的几类功能依赖环境中的外部程序或密钥，未配置时界面会给出明确错误提示（不会静默失败）：

| 功能 | 必需配置 | 说明 |
| --- | --- | --- |
| PDF 翻译（pdf2zh） | `PAPER_TRANSLATE_PDF2ZH_BIN` 指向 pdf2zh 适配包装脚本（或 node 包装 `.js/.cjs`）；OpenAI 兼容翻译端点密钥 `OPENAI_API_KEY`/`OPENAI_BASE_URL`/`OPENAI_MODEL` | 配置细节见 `docs/research-workbench/T3.2-sidecar-spike.md` |
| 知识库问答（paper-qa） | `RAG_SIDECAR_BIN`（指向 sidecar 脚本）+ `OPENAI_API_KEY` 等 LLM/embedding 端点变量 | 配置细节见 `docs/research-workbench/T4.1-rag-spike.md` |
| LaTeX 编译 | `TECTONIC_BIN` 指向 tectonic 可执行文件（或加入 PATH） | 见 `docs/research-workbench/T3.3-latex-spike.md` |
| 绘图 PPTX 导出 | `RESEARCH_FIGURE_PPTX_PYTHON`（含 python-pptx 的 Python） | 见 `docs/research-workbench/T4.4-figure-pptx-spike.md`，未配置时 SVG 仍可用 |

模型策略：**全局 API-first**——所有 LLM/embedding/翻译均走 API 服务商（OpenAI 兼容端点），不在本地运行模型。

## 2. 科研工作台导航

登录后进入「科研工作台」（页面顶部研究页签区），包含五个页面：

| 页签 | 路由 | 功能 |
| --- | --- | --- |
| 工作流 | `/research/workflows` | 可视化 DAG 工作流（画布、模板、运行与历史） |
| 文献 | `/research/papers` | 论文库：导入、列表、PDF 预览、发送到聊天 |
| LaTeX | `/research/latex` | LaTeX 编辑、tectonic 编译、错误面板、实时预览 |
| 知识库 | `/research/knowledge` | paper-qa RAG 知识库：建库、索引、问答 |
| 成果 | `/research/artifacts` | 研究成果产物（后续版本完善） |

## 3. 文献库

### 3.1 导入 PDF

「文献」页 →「导入 PDF」按钮 → 选择本地 PDF（仅支持 PDF 文件，超过大小限制会被拒绝）。导入成功后列表显示：标题（默认取文件名）、文件名、大小、导入时间、标签。

### 3.2 查看与预览

- 点击列表行进入预览页；预览使用浏览器原生 PDF 查看器，通过 HTTP Range 流式加载，**大 PDF 也能快速打开**（按需拉取页面数据，不需整个下载）。
- 预览页左上「返回文献列表」返回。
- 文献详情支持修改元数据（标签等），删除需二次确认，删除会同时移除磁盘文件。

### 3.3 发送到聊天

列表行「发送到聊天」按钮 → 选择目标会话（或新建聊天）→ 消息以文本形式发出（含论文标题、元数据、文件路径），点击会话名可直接跳转到该会话。发送后即可在聊天中看到消息。

## 4. PDF 翻译（翻译队列）

「文献」页（或后续版本翻译入口）提交翻译任务：

1. **提交任务**：选择 PDF、目标语言，任务进入队列（状态 `running` 时不可重复提交同一任务）。
2. **任务状态**：`queued`（排队中）→ `running`（运行中）→ `completed`（完成）/ `failed`（失败）。失败时任务详情给出错误原因；`failed` 任务可点「重试」。
3. **查看产物**：完成后可查看：
   - `-mono.pdf`：单语译文（原文替换为译文）
   - `-dual.pdf`：双语对照页（原文/译文按行对照），浏览器内直接打开预览。
4. **版本说明**：翻译引擎为 pdf2zh 家族（1.x/2.x/next 均兼容，经 `PAPER_TRANSLATE_PDF2ZH_BIN` 适配包装脚本统一）。首次运行可能需要模型布局文件（网络受限环境设置 `HF_ENDPOINT=https://hf-mirror.com`）。

常见失败：缺少 `OPENAI_API_KEY`（任务会快速失败并明确提示）；无 key 时可使用 pdf2zh 的 google 后端复现双语效果。

## 5. LaTeX 写作

### 5.1 编辑

「LaTeX」页 →「新建」创建文档（自动附带模板论文源码）→ 左侧编辑源码（标题/源码区/保存）→ 右侧为 PDF 预览区。

### 5.2 编译与定位

- 「编译」：任务排队/运行中提示对应状态；编译完成后预览区自动刷新为最新 PDF。
- **错误面板**：编译失败时信息区列出错误（文件、行号、消息），点击错误行，编辑区自动定位并选中对应源码行。
- 同一文档同时只允许一个编译任务（重复触发给出提示）。
- 编译器未配置时给出明确提示（配置 `TECTONIC_BIN`）。

## 6. 知识库（paper-qa RAG）

### 6.1 建库与索引

「知识库」页：

1. 「新建知识库」：填名称、描述。
2. 向知识库添加论文成员（从文献库挑选）。
3. 点「索引」：对库内 PDF 建立检索索引。索引状态：`未索引 → 索引中 → 已索引`；**添加/移除成员后状态自动变为「过期」，需要重新索引**。
4. 索引失败/中断会明确提示；章节概览显示已索引文档数与分块数。

### 6.2 问答与引用溯源

- 知识库详情页「提问」面板输入问题 → 答案卡片展示，**引用列表**显示：论文标题、页码、原文片段。
- 点击引用 → 跳转到「文献」预览页对应论文。
- 未配置 sidecar/密钥时提问立即失败并提示原因，不静默。

## 7. 聊天与知识库

### 7.1 @ 选择知识库

聊天输入框输入 `@` 弹出知识库选择浮层（支持输入过滤、上下键/回车选择、Escape/点击外部关闭）。选中后：

- 输入框中的 `@知识库名` 被移除，会话顶部出现选中态标签（显示名称与索引状态，可移除）。
- 选择按会话隔离：每个会话可独立选择不同知识库。

### 7.2 问答与溯源

选中知识库后发送**纯文本**消息 → 系统走知识库问答：消息发出后出现思考中占位，答案以助手消息回贴，消息内展示引用列表（标题/页码/片段），点击引用跳转论文预览页。

- 带附件或 `/` 命令的消息保持普通聊天路径（不会丢弃附件）。
- 问答失败/超时在聊天内以系统错误提示呈现（含原因），不静默。
- 未选择知识库时，聊天行为与普通聊天完全一致。

## 8. 聊天 VCP 渲染卡片

聊天消息中的特定代码围栏会被渲染为「VCP 卡片」（设计参考 dsh-raw-html）：

| 围栏语言 | 渲染方式 |
| --- | --- |
| ` ```html ` | 沙箱 iframe 卡片（脚本隔离：无同源权限；可折叠/展开、高度档位调节） |
| ` ```svg ` | 完全隔离 iframe（无脚本权限，封锁一切脚本/事件） |
| ` ```mermaid ` | Mermaid 图表渲染为 SVG 卡片（失败回退为代码块并提示） |
| ` ```math ` / ` ```katex ` | KaTeX 公式渲染（失败回退为代码块） |

**双开关**（聊天窗口头部图标按钮）：

- **VCP 渲染**（默认关）：关时 html/svg 回退为普通代码块（mermaid/katex 保持基座内联渲染，不回归）。
- **美学渲染**（默认开）：卡片视觉增强样式。

安全说明：用户/模型提供的 HTML 永远不会获得网页同源权限；SVG 完全禁止脚本。

## 9. 工作流

### 9.1 画布与节点

工作流是可视化 DAG：

- **Agent 节点**：传统聊天式节点，运行会话由其驱动（需要聊天运行环境）。
- **确定性节点**（科研扩展类型）：`script`（运行 Node 脚本）、`validate`（校验）、`render`（渲染）。确定性节点**不创建聊天会话**，由引擎直接执行，产出写入节点输出栏，可复现、可中断续跑。

画布操作：从托盘拖入节点（或工具栏创建）、连线、配置（script 节点可编辑标题/代码，validate/render 可编辑标题、可编辑运行时字段）、保存/载入。载入时未知类型节点原样保留（字段不丢失），保存时仅剥离画布运行时字段。

### 9.2 运行 / 停止 / 重跑

- 「运行」：整个 DAG 按依赖顺序执行；agent 节点进入聊天运行，确定性节点执行脚本。
- 「停止」：立即中止运行中的任务——**确定性脚本的子进程树会被强制终止**（Windows 下无孤儿），节点行与运行行以 `canceled` 落终态。
- 「重跑」：从任意节点重跑其下游；同一工作流同一时刻只允许一个运行，冲突时明确提示。
- 运行历史展示每个节点的状态与输出（确定性节点输出在运行详情查看）。

### 9.3 科研模板

模板页可从模板库创建，已内置四个科研模板（在「工作流」页从模板新建）：

| 模板 | 用途 | 产物 |
| --- | --- | --- |
| 文献综述（literature-review） | 按提纲多Agent协作产综述 | 综述 HTML 报告 |
| 论文翻译（paper-translate） | PDF 接入 → pdf2zh 翻译脚本 → 双语对照 HTML | mono/dual PDF + 对照页 |
| 过夜科研（overnight-research） | 读取 JSONL 队列夜间批量处理，晨报汇总 | `morning-report.html`（批处理统计/逐项结果/失败原因/下一步） |
| 绘图（figure-drawing） | 输入绘图 brief → Agent 生成绘图脚本 → 确定性渲染 | `figure.svg`（可选 `figure.pptx`，需 python-pptx） |

**过夜科研的队列文件格式**（JSONL，每行一个任务）：

```json
{"id":"q-001","type":"literature","payload":{...}}
{"id":"q-002","type":"experiment","payload":{...}}
```

细节：重复 id 只保留首次；非 JSON/缺 id 行计入「无效行」（不静默丢弃）；`batchSize` 可调（默认 3）。晨报与队列文件同目录。

**绘图 brief 格式**：

```json
{"title":"柱状图","figureType":"bar","labels":["A","B"],"data":[...]}
```

### 9.4 运行完成通知

运行结束（完成/失败）时，若浏览器允许通知权限，会弹出系统通知（含运行名与状态，点击跳转运行详情）；权限未授权时降级为页面内提示。

## 10. skill 包管理

科研 skill 包（论文精读、图表规范、综述提纲、审稿式自查、科研绘图规范）可在「工作台」对应管理页装载到 Agent 可发现的技能目录：

| 状态 | 含义 |
| --- | --- |
| 已安装（installed） | 已装载且与包源一致 |
| 过期（outdated） | 包源已更新，重新装载即可升级 |
| 已修改（modified） | 你改过已装载的技能——重新装载时**保留你的修改**；「强制重载」才会覆盖 |
| 冲突（conflict） | 同名技能被其他来源改动过——**永不被覆盖** |
| 缺失（missing） | 目标文件丢失，重新装载恢复 |

卸载只移除本包登记过的文件，不会误删同名其他来源的技能。绘图工作流依赖于「科研绘图规范」技能已装载（未装载时建模运行会给出明确错误）。

## 11. 常见问题（FAQ）

**Q：翻译/问答任务立即失败并提示缺 API key？**
配置 OpenAI 兼容端点环境变量（`OPENAI_API_KEY`/`OPENAI_BASE_URL`/`OPENAI_MODEL`），或使用无需 key 的 google 翻译后端（见 spire 报告）。

**Q：LaTeX 编译提示没有 Tectonic？**
设置 `TECTONIC_BIN` 指向 tectonic 可执行文件，或将其加入 PATH。

**Q：上传大 PDF 很慢？**
预览是 Range 流式加载，首次打开后按需加载，等待时间与文件大小无关；上传大小限制见服务端配置。

**Q：知识库引用没法跳转？**
论文被删除时预览页会优雅降级（显示未命名文献），重新索引后引用恢复。

**Q：聊天里同学 / 医生等字符被识别成 @知识库？**
`@` 需要以空白/行首开头并紧跟知识库名才会触发；正常邮件地址不含空白不会误触发。

## 12. 已知限制

- 对话内的知识库问答（提问与回答）已持久化到服务端会话历史，刷新页面后仍在；引用元数据随回答保留、可继续点击跳转。
- 翻译/索引/编译类任务需要各自 sidecar 与密钥，环境内未配置时功能不可用（错误可见）。
- 过夜科研的晨报「下一步建议」由 `or-next-steps` Agent 基于聚合台账自动生成（3-5 条，覆盖失败/缺失补救、低完成率处理、可并行/可自动化后续动作）；建议输出为空或无法解析时，第四节回退为占位文案并标注「自动建议生成失败」，不影响运行完成。
- 图纸 PPTX 映射能力 v2：rect/circle/ellipse/line/polyline/polygon 之外，还支持 path（M/L/H/V/C/S/Q/T/Z，A 圆弧按折线近似）、rotate 变换、渐变填充（取代表纯色，描边保留）与 text+tspan（多段落/多 run）；导出结果附 `svgFeaturesMapped`/`svgFeaturesSkipped` 计数。裁剪、蒙版、filter 与嵌套复杂变换仍不映射，此类复杂图形建议以 SVG 为最终形态。
- 绘图 skill 绑定是硬依赖：未装载技能包时绘图建模拒跑。
