## 1. 设计概述

### 1.1 设计目标

在多 Agent 本地运行时基座之上，构建面向科研场景的一站式工作台。设计围绕三条主线展开：

1. **确定性工作流**：将科研方法固化为"确定性脚本为主、大模型为辅"的 DAG 流程，保证过程可复现、可中断续跑、失败可见；
2. **论文工作台**：文献、翻译、写作、产物四类资产的本地化管理与流式访问；
3. **智能协同**：以聊天为协同载体，提供带引用溯源的知识库问答与沙箱化的富内容渲染。

### 1.2 设计约束

| 约束 | 说明 |
| --- | --- |
| 基座同源 | 基座代码与上游仓库同源，自研改动必须附加式、向后兼容，并逐条登记（BC 机制），保证上游可合并 |
| 模块边界 | 服务端按业务域分模块（studio/research/hermes/ekko/coding-agents），模块间仅允许经 `public` 门面调用，由边界检查脚本强制 |
| API-first | 智能能力全部经 OpenAI 兼容 API 接入，不本地运行模型权重；密钥仅经环境变量传递 |
| 零冗余依赖 | 前端渲染能力（mermaid/KaTeX/highlight.js）复用基座既有依赖，自研部分零新增 npm 依赖 |
| 运行环境 | Node.js ≥ 23；Windows 为一等公民（进程树终止、路径语义、盘符与 ADS 防御均显式处理） |

### 2.3 请求与数据流

- **页面数据**：浏览器 → Koa 路由（JWT 鉴权，注册于代理 catch-all 之前）→ 控制器 → 服务 → 各域自有 SQLite/文件存储；

- **文件流**：PDF/产物统一经支持 HTTP Range（单区间 206/416 语义）的流式端点输出，供浏览器原生查看器渐进加载。

## 3. 确定性工作流引擎（核心设计）

### 3.1 节点模型

| 节点类型 | 执行者 | 会话 | 职责 |
| --- | --- | --- | --- |
| `agent` | 聊天运行时（大模型） | ✅ | 理解与写作；可绑定技能（注入 SKILL.md 全文到提示词） |
| `script` | 确定性执行器（真实 Node 子进程） | ❌ | 机械环节：校验、聚合、报告生成、文件处理 |
| `validate` / `render` | 执行器（一期为显式占位） | ❌ | 校验/渲染类扩展位 |

**脚本五字段契约**：每个 script 节点必须且只能声明 `title / input / orchestration / runtime('node') / code`。引擎加载时对缺失 runtime 的历史数据做显式失效标记（不静默改写），保存前做确定性专属校验，未知节点类型显式拒绝。

### 3.2 执行生命周期与资源安全

确定性节点执行遵循严格的资源安全模型（BC-5 加固后形态）：

1. **停止传播**：`stopRun` 为每个确定性节点建立 AbortController，经运行时契约将 `AbortSignal` 传入执行器；deadline 超时同样先 abort 再失败。信号到达即终止**整棵进程树**（Windows 走 `taskkill /T /F`，POSIX 直接 kill）。
2. **输出上限**：stdout/stderr 各设 5MB 硬上限，超限立即杀树并以结构化错误结算（杜绝内存膨胀型失控脚本）。
3. **单次结算**：abort/超时/超限/正常退出统一经幂等结算闸门，保证节点行只写一次终态。
4. **rerun 防护**：重跑与首跑共用工作流级运行许可（admission），终态复位采用 `UPDATE ... WHERE status=?` 原子 CAS（影响行数 ≠1 即 409），执行标识改用随机 UUID 避免唯一索引冲突。
5. **输出落盘**：脚本 stdout 即节点输出，落 `output_json` 列（必填字符串），重跑恢复与运行详情均从该列读取。

### 3.3 模板契约与输入协议

- **模板契约**：节点调色板白名单、script 五字段精确校验、agent 字段全有或全无、单入口 + 全节点可达、技能绑定合法性；
- **引擎输入协议**：引擎将上游输出包装为 `[Workflow upstream results]` / `[Upstream: <节点标题>]` / `[Current task]` 段落后注入 stdin。脚本侧提供两级标准处理：
  - `stripEngineWrapperLines()`：剥除全部包装行后再解析（入口/报告类节点）；
  - `splitUpstreamSections()`：按 `[Upstream: ...]` 头分节后逐节处理（菱形汇聚节点），支持按内容形态识别节、与标题无关。
- 模板 e2e 测试统一采用"mock 智能层 + 真实确定性执行器"模式：script 节点由真实 Node 子进程执行，外部二进制以契约兼容的包装脚本替身，断言运行终态、产物落盘与"无包装行泄漏"。

### 3.4 快照与恢复

运行启动时冻结节点/边快照；确定性输出持久化后，画布回放与中断续跑（rerun-from-node）以快照 + `output_json` 还原现场，上游缺失输出时 fail-closed（409）。

## 4. 科研功能模块设计

### 4.1 文献库（library/papers）

- **存储**：元数据 SQLite（`<状态目录>/research/papers.db`），PDF 字节以 UUID 命名落盘（用户输入不接触文件系统路径）；
- **流式预览**：`GET /papers/:id/file` 支持 HTTP Range（单区间 206、后缀区间、超 EOF 钳制、越界 416 `bytes */size`、非法/多区间回落 200、HEAD 仅元数据不开流）——大 PDF 由浏览器原生查看器按需拉取；
- **脱敏视图**：对外响应统一经 `PaperView` 序列化层，不暴露内部 `file_path`；
- **删除**：登记行与磁盘文件连带删除，删除路径以数据库内 UUID 记录为唯一来源。

### 4.2 学术翻译（library/translation）

- **状态机**：`queued → running → completed | failed`（仅 failed 可重试）；串行 worker（并发=1）；服务重启时将遗留 running 任务置 failed；
- **sidecar 契约**：与模板共用 `PAPER_TRANSLATE_PDF2ZH_BIN`（支持 node 包装脚本，1.x/2.x 发行版 CLI 差异全部收敛在包装层）；参数数组 + `shell:false`；密钥仅经环境变量；超时经公共门面杀进程树；
- **优雅关停**：研究域资源（worker、三库连接）注册进基座 `additionalShutdownSteps`，关停顺序化；
- **产物预览**：mono/dual PDF 经自带 Range 端点输出；双语对照 HTML 内嵌 PDF 改走运行文件代理（见 4.8）。

### 4.3 论文写作（latex）

- **编译队列**：文档级串行、并发提交 409 防重入、超时杀进程树、单次结算；服务重启时将遗留 queued/running 编译对账为 failed；
- **错误解析**：同时解析 tectonic 的 rustc 风格摘要行（容忍 `error:` 前缀）与经典 TeX transcript（`! msg` + `l.N`，含文件括号跟踪），输出 `{file, line, message}`；前端错误面板点击后按行号选中源码行；
- **编辑器**：语法高亮采用"透明 textarea + 高亮层"overlay 方案，高亮复用基座 highlight.js 的 latex 语言（零新依赖）；像素度量（字号/行高/内边距）单源定义并被测试钉死；超 200KB 自动降级；
- **产物**：编译 PDF 登记进成果注册表。

### 4.4 知识库 RAG（rag）

- **模型**：collection（成员引用论文库）— 索引任务 — 问答任务三元模型；成员变更使 `indexed → stale`；重启对账清录 running/queued 残留；
- **sidecar 协议**：stdin 单个 JSON（`{action: index|ask, papers, question}`）→ stdout 取最后一个含 `status` 的 JSON 响应（容忍日志横幅污染，2MB 流上限）；`RAG_SIDECAR_BIN` 支持 node 包装脚本/Python/原生二进制；
- **安全**：子进程环境变量白名单（仅 API 密钥与模型配置，无关机密断言剔除）；缺密钥/未配置 503 快速失败不 spawn；citations 按库成员过滤；
- **聊天集成**：`POST /rag/chat-asks` 服务端编排——校验 → 确保会话存在 → 追加用户消息 → 问答 → 答案消息落历史；引用经绑定表（question ↔ 消息 id）在客户端水合，刷新与换设备均可溯源；客户端轮询带 15 分钟护栏与切库终止。

### 4.5 聊天协同

- **@知识库**：输入框 @ 提及（输入法合成结束同步刷新、光标移动保护防前缀复制）、按会话持久化选择（localStorage + 懒校验失效清理）；
- **VCP 渲染**：对 ```html / ```svg / ```mermaid / ```math 围栏渲染沙箱卡片——html 卡 `sandbox="allow-scripts"`（无同源权限）、svg 卡 `sandbox=""`（全隔离）、payload 经编码占位 + 程序化属性赋值（永不走 v-html 直插）、渲染失败降级代码块；渲染/美学双开关持久化；
- **产物发送**：论文/产物经统一弹窗选择会话，消息体为纯文本（不含临时令牌、不含会被误判为文件卡片的相对链接）。

### 4.6 运行文件代理（run-files）

`GET /api/studio/research/run-files?path=` 将运行产物（如双语 PDF）以 Range 流式提供给浏览器内嵌页面。安全链：绝对路径校验 → 规范化 + 词法 `..` 拒绝 → NTFS ADS 冒号拒绝 → 词法包含性检查 → `realpathSync`（符号链接/junction 逃逸）→ 大小写不敏感的包含性复查 → 仅允许 `.pdf` → 越界一律 403/404。

### 4.7 科研技能（skillpacks）

- **装载模型**：技能包（SKILL.md 资产集）平铺复制到运行时技能目录，manifest 记录源/装双 sha256；状态机 `installed / outdated / modified / conflict / missing`；
- **保护语义**：用户改动（modified）不 force 不覆盖；冲突目录任何情况下不接管；卸载仅移除 manifest 归属文件；
- **模板集成**：agent 节点声明 `skills: [...]`，preflight 对未装载技能硬拒绝（409）；流程中心在模板卡片展示技能状态标签，创建流程时对 missing/outdated 自动装载（modified/conflict 刻意跳过并警示）；
- **profile 校验**：装载目标 profile 必须属于已知名单，防任意目录写入。

### 4.8 成果注册表（artifacts）

产物登记（LaTeX 编译 PDF 自动登记；工作流产出随后续版本接入）→ 列表（类型筛选/关键字过滤）→ 元数据预览（HTML 产物沙箱内嵌）→ 删除（仅移除登记行）→ 发送到聊天。响应统一脱敏，不暴露服务端内部路径。

### 4.9 通知

工作流运行进入终态时经统一通知设施（桌面桥 / 浏览器 Notification / Service Worker）发出系统通知：跨标签去重（Web Locks + 共享台账）、前台抑制可选、点击深链至运行详情；权限未授权时降级为页内提示。

## 6. 安全设计

| 面 | 设计 |
| --- | --- |
| 鉴权 | 全部业务路由挂 JWT 中间件，注册于代理 catch-all 之前；流式/下载类端点支持 `?token=` 查询参数（与基座导出下载同模式） |
| 路径安全 | 用户输入永不拼接文件路径（UUID 存储 / 服务端计算产物路径）；运行文件代理执行"规范化 + realpath + 大小写不敏感包含性 + 扩展名白名单"五重校验；穿越/编码/ADS/符号链接逃逸均有测试 |
| 子进程 | 结构化参数数组 + `shell:false`；超时与停止统一杀进程树；输出上限；退出兜底；单次结算防双写 |
| 密钥 | 仅经环境变量注入子进程（白名单构造），不出现在 argv/日志/数据库；无关机密断言剔除 |
| 前端注入 | VCP 卡片沙箱矩阵（html 无同源、svg 全隔离）；占位符编码 + 程序化 DOM 属性赋值；LaTeX 高亮层先转义后包裹 token |
| 技能目录写保护 | 哈希归属 + modified/conflict 拒绝覆盖 + profile 白名单 |

## 7. 前端设计

- **壳层**：应用侧边栏仅保留科研工作台（一级入口、默认落地）、单聊、工作流、历史、模型配置与设置；品牌名「SEU科研工作台」贯穿标签页/PWA/登录页；
- **研究壳**：五页签共享 `ResearchPageShell`（页签导航 + 内容槽），各页签独立 Pinia store + API helper（统一经 `client.ts` 请求封装，流式/下载带令牌）；
- **国际化**：11 种语言（ar/de/en/es/fr/ja/ko/pt/ru/zh/zh-TW），键结构齐平由测试强制（含运行时编译 smoke 与非西文 RTL 逻辑属性检查）；
- **画布**：Vue Flow 承载 DAG；确定性节点卡片支持配置与只读回放，未知类型节点无损往返（仅剥离运行时 UI 字段），无效脚本节点加载期标记、保存期拦截。
