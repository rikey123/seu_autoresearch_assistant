## 2. 设计：SVG 约束词表 → 原生形状映射

关键取舍：**不嵌入 SVG 位图**（python-pptx 原生不支持 SVG 图片，转 PNG 需要重量级渲染依赖），而是让绘图 agent 按 `scientific-figure-style` 技能钉死的词表出图（rect/circle/ellipse/line/polyline/polygon/text + g 平移），sidecar 把词表逐元素映射为**原生可编辑形状**：

| SVG 元素 | pptx 形状 | 说明 |
| --- | --- | --- |
| `rect`（rx>0） | ROUNDED_RECTANGLE | fill/stroke 颜色、线宽随迁 |
| `rect`（rx=0） | RECTANGLE | 同上 |
| `circle` / `ellipse` | OVAL | r/rx/ry → 外接框 |
| `line` | STRAIGHT connector | stroke/stroke-width → 线色/线宽 |
| `polyline` / `polygon` | 连续 STRAIGHT connector | 逐段连线（填充不保） |
| `text` | textbox | y 基线→框顶上移一个字号；text-anchor middle/end 按估算宽度回退；px→pt（×0.75）；font-weight bold 随迁 |
| `g transform="translate/matrix"` | 坐标平移累加 | 只取平移分量 |

画布：幻灯片尺寸直接设为 SVG 的 width/height（96 px/in → 9525 EMU/px），900×560 SVG → 900×560 px 幻灯片，坐标零缩放失真。标题写入 core_properties。z-order 按 SVG 文档顺序保持。

## 3. 门控机制（不可用即优雅降级）

pptx 导出是 figure-drawing 模板的**可选第 4 节点**（确定性 script 节点，无引擎改动）：

- `RESEARCH_FIGURE_PPTX_PYTHON` 未设置或 sidecar 路径（`RESEARCH_FIGURE_PPTX_SIDECAR`，必须绝对路径）缺失 → 节点输出 `{"pptxExported": false, "reason": ...}` **正常退出**，run 照常 completed，`figure.svg` 为主产物。
- 已设置 → spawn（argv 数组、shell:false）执行 sidecar；产物缺失/非零退出同样降级并带 stderr 尾部原因。
- 两个环境变量均已登记在模板 `optionalEnv`，API 层可见。

**教训记录**：脚本节点在 run 工作区目录内执行（引擎传 workspace 为 cwd），一切「按仓库布局猜相对路径」的默认值都不可靠——sidecar 路径因此必须用绝对路径环境变量，而不是 cwd 相对默认值（实现期发现并已修正）。

## 5. 已知限制与生产部署清单

- SVG 子集约束（v1 历史记录）：`tspan`、贝塞尔 `path`、渐变、旋转（除 g 平移）不映射——**v2 已解除其中 path/rotate/渐变/tspan 四类，见第 6 节**；裁剪、蒙版、filter、嵌套复杂变换仍不映射，越界时由 render/导出节点确定性报错或计数降级，不静默失真。
- 文本宽度为估算值（len×0.62×字号），`text-anchor=end` 的长标签可能偏移数像素；不影响数据图元。
- px→pt 固定 ×0.75（96dpi 假设）。
- 部署清单：Python 3.10+ venv + `pip install python-pptx`（GFW 内网加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）；服务端环境变量设 `RESEARCH_FIGURE_PPTX_PYTHON=<venv python 绝对路径>`、`RESEARCH_FIGURE_PPTX_SIDECAR=<仓库>/packages/server/src/modules/research/workflows/scripts/figure_svg_to_pptx.py`。
- 人工复现：
  1. `python -m venv %TEMP%\figure-pptx-spike\venv && %TEMP%\figure-pptx-spike\venv\Scripts\pip install python-pptx`；
  2. `RESEARCH_FIGURE_PPTX_PYTHON=<venv python> HERMES_FIGURE_PPTX_SMOKE=1 npx vitest run tests/server/research-figure-drawing-e2e.test.ts` 应全绿（v2 起 11 用例，含门控 2 例）。

## 6. 映射能力 v2（P7 工单 4，分支 `feature/p7-pptx-svg`）

在 v1 词表（rect/circle/ellipse/line/polyline/polygon/text + g 平移）之上，sidecar 的映射面扩展为四类新能力，**全部仍为原生可编辑形状，不引入位图**：

| 能力 | 精度 | 策略 |
| --- | --- | --- |
| `path` M/L/H/V/C/S/Q/T/Z | 精确（贝塞尔按 `CURVE_SAMPLES=16` 采样拉直） | 每个子路径一个 freeform 形状；`Z` 走 freeform 闭合边；隐式命令重复（`L 1 1 2 2`）展开；控制点反射（S/T）按 SVG 规范仅在同类前驱命令间生效 |
| `path` A/a 圆弧 | **近似降级**（折线，≥5°/采样点，计数上报） | SVG 规范 F.6.5 端点参数化 → 圆心参数化 → 均匀采样；半径退化（rx/ry=0）塌缩为直线 |
| `transform="rotate(a cx cy)"`（含 translate/matrix/scale 组合，解析为仿射） | 点映射形状（line/polyline/polygon/path）**精确**；bbox 形状（rect/circle/ellipse/text）对 rotate+translate **精确** | bbox 形状：中心经仿射映射 + `shape.rotation`（SVG 与 pptx 同为 y-down 顺时针，角度直传）；绕外点旋转按「中心绕轴公转 + 自转」换算。仿射含 scale/skew 时 bbox 形状无法保真，忽略并计入 `scaleOnBoxShapeIgnored` |
| `linearGradient`/`radialGradient` | **代表色近似** | `fill="url(#id)"` 解析为单一代表色：stop 按 offset 梯形加权平均（两 stop 等价于首尾中点混合，如 #FF0000→#0000FF → #800080）；描边一律原样保留（`stroke` 走同一解析表，未知 url 回退黑） |
| `text` + `tspan`（x/y/dx/dy + font-size/fill/font-weight 覆盖） | 行内 tspan **精确**；跨段位置为已记录的近似 | 选定实现：**同一文本框内多段落** —— 带 x/y 或非零 dy 的 tspan 开新段落（dy 即"下一行"惯用法），纯样式 tspan 并入当前段落为**多 run**，字号（px×0.75→pt）/颜色/加粗逐 run 保留；各段落 x 收敛到框左缘（仅首行保留 text-anchor 估算），行内 dx 被吸收——均为注释明示的取舍 |

**能力报告**：stdout JSON 新增 `svgFeaturesMapped` / `svgFeaturesSkipped` 计数（如 `{"path": 3, "rotate": 2, "gradientFill": 1, "tspanParagraph": 1}` / `{"arcApproximated": 1}`）。fd-pptx 节点成功时把它们**追加**进节点输出（v1 键名与语义全部不变，旧 sidecar 无计数也照常成功）——stdout 契约只增不破，晨报/产物语义不受影响。模板 `optionalEnv` 描述同步更新为 v2 口径。

**非门控守约测试**：`tests/server/research-figure-pptx-sidecar.test.ts`（argv 契约 + v2 词表源级断言 + 有 Python 时 `py_compile`；无 Python 自动跳过，CI 保持密闭）。

**门控真实链路**（gated describe 新增第 2 用例）：含 path(贝塞尔+折线+圆弧)/rotate(绕心 45°、绕外点 30°)/渐变/tspan 的 SVG 走完整 intake→agent→render→pptx 链路，python-pptx 回读断言：3 个 FREEFORM（渐变代表色 #800080、圆弧位置正确）、rotation 45°/30°（外点旋转的中心落点 (475, 236.7) 误差 ≤1px）、同一文本框 2 段落且第二段 2 个 run（9pt #D55E00 / 7.5pt #6B7280）。实测门控开启 11/11 全绿（v2 用例 1.5s），门控关闭 9 绿 + 2 skip。

**v2 后残余限制**：圆弧为折线近似（可分辨率换精度）；渐变只有单代表色；tspan 跨段 x 收敛、行内 dx/dy 吸收；裁剪/蒙版/filter/嵌套变换仍不映射；px→pt 固定 ×0.75。
